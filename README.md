# PM2.5 ไทย

เว็บแสดงและวิเคราะห์ค่าฝุ่น PM2.5 ของประเทศไทยระดับ จังหวัด → อำเภอ/เขต → ตำบล/แขวง
เป็นหน้าเว็บ static (HTML + CSS + JavaScript) ไม่ต้องมี backend หรือ API key

## ทำอะไรได้

- **แผนที่ + ค่าฝุ่นปัจจุบัน** สีตามเกณฑ์ของกรมควบคุมมลพิษ (5 ระดับ) พื้นหน้าเว็บเปลี่ยนสีตามระดับอากาศของพื้นที่ที่เลือก
- **เลือกพื้นที่** พิมพ์ค้นหาได้ทั้งจังหวัด อำเภอ/เขต ตำบล/แขวง (77 จังหวัด, 875 อำเภอ/เขต, 7,124 ตำบล/แขวง) หรือคลิกจุดบนแผนที่เพื่อเจาะลึก
- **ใช้ตำแหน่งของฉัน** หาตำบลที่ใกล้ที่สุดแล้วบอกว่า "แถวคุณ" ฝุ่นเป็นอย่างไร
- **แนวโน้ม 7 วันย้อนหลัง + พยากรณ์ 3 วัน** พร้อมเส้นเกณฑ์ไทย (37.5) และ WHO (15) และเทียบกับเมื่อวานเวลาเดียวกัน
- **ฝุ่นช่วงไหนของวัน** เฉลี่ยรายช่วง 6 ชั่วโมง (ดึก/เช้า/บ่าย/เย็น-ค่ำ)
- **ฝุ่นกับสภาพอากาศ** ความสัมพันธ์ระหว่างฝุ่นกับลม ฝน อุณหภูมิ ความชื้น (สหสัมพันธ์เพียร์สัน, รายชั่วโมง 7 วัน)
- **อันดับ** อำเภอ/ตำบลที่ฝุ่นสูงสุดในจังหวัดที่เลือก และสรุปรายภาค
- **ส่งออก** ดาวน์โหลดข้อมูลเป็น CSV และบันทึกกราฟเป็น PNG

## วิธีรัน

เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย (ต้องต่ออินเทอร์เน็ต เพราะดึงข้อมูลและไลบรารีจาก CDN)
ปุ่ม "ใช้ตำแหน่งของฉัน" ทำงานได้เสถียรที่สุดเมื่อเปิดผ่าน `https://` หรือ `http://localhost`

## โครงสร้าง

```
index.html      โครงหน้าเว็บ
css/style.css   สไตล์
js/config.js    เกณฑ์สี/ระดับ/คำแนะนำ และชื่อภาค
js/admin.js     ข้อมูลจังหวัด/อำเภอ/ตำบล พร้อมพิกัดกึ่งกลาง
js/app.js       ดึงข้อมูล คำนวณ และวาดผล
```

## ข้อมูลและวิธีคำนวณ

| ส่วน | แหล่งที่มา |
|---|---|
| PM2.5 (ปัจจุบัน/ย้อนหลัง/พยากรณ์) | [Open-Meteo Air Quality API](https://open-meteo.com/en/docs/air-quality-api) |
| ลม ฝน อุณหภูมิ ความชื้น | [Open-Meteo Weather API](https://open-meteo.com/en/docs) |
| พิกัดตำบล/อำเภอ/จังหวัด | [kongvut/thai-province-data](https://github.com/kongvut/thai-province-data) |
| แผนที่ | OpenStreetMap + [Leaflet](https://leafletjs.com) |
| กราฟ | [Chart.js](https://www.chartjs.org) |
| เกณฑ์สีและระดับ | กรมควบคุมมลพิษ (ค่าเฉลี่ย 24 ชม.: ≤15, ≤25, ≤37.5, ≤75, >75 µg/m³) |

- **ค่าเฉลี่ยของพื้นที่** (เช่น ทั้งประเทศ, ทั้งจังหวัด) คือค่าเฉลี่ยเลขคณิตของจุดย่อยที่แสดงอยู่ ไม่ถ่วงน้ำหนักด้วยประชากรหรือพื้นที่
- **ตำบล/อำเภอ** ใช้จุดกึ่งกลาง (ค่าเฉลี่ยพิกัดของตำบลที่อยู่ในนั้น) ไปขอค่าจากโมเดล โดยปัดพิกัดเป็นกริด 0.1° เพื่อลดจำนวนคำขอ
- **สหสัมพันธ์** คำนวณระหว่างค่าฝุ่นเฉลี่ยรายชั่วโมงกับค่าอากาศที่จุดกึ่งกลางพื้นที่ ณ ชั่วโมงเดียวกัน
- **ใช้ตำแหน่งของฉัน** หาตำบลที่จุดกึ่งกลางอยู่ใกล้ที่สุด ตำแหน่งจริงของผู้ใช้อยู่ในเบราว์เซอร์เท่านั้น ไม่ถูกส่งไปที่ใด

## ข้อจำกัด (สำคัญเมื่อตีความผล)

1. **ค่าฝุ่นเป็นผลจากโมเดล ไม่ใช่เครื่องวัดจริง** ความละเอียดราว 10 กม. ตำบลที่อยู่ใกล้กันมักได้ค่าเท่ากัน อันดับระดับตำบลจึงมีค่าเสมอกันเยอะ และไม่ควรตีความว่าตำบลใดฝุ่นมากที่สุดจริง ๆ ถ้าต้องการความแม่นยำ ควรใช้ข้อมูลสถานีวัด (เช่น Air4Thai)
2. **กรุงเทพฯ แสดงเป็นจุดเดียว** เพราะชุดข้อมูลพิกัดไม่มีพิกัดของเขต/แขวง นอกจากนี้ตำบลนอก กทม. อีก 133 แห่งไม่มีพิกัดในชุดข้อมูลจึงไม่อยู่ในรายการ (รวมทั้งหมดที่ใช้ได้ 7,124 จาก 7,436 แห่ง)
3. **ตำบลที่ใกล้ที่สุด ≠ ตำบลที่อยู่จริง** ข้อมูลมีแค่จุดกึ่งกลาง ไม่มีขอบเขต ตำแหน่งจากคอมพิวเตอร์ยังคลาดเคลื่อนเป็นกิโลเมตรได้ จึงมีปุ่มให้เลือกตำบลข้างเคียง
4. **สหสัมพันธ์ไม่ใช่เหตุและผล** ข้อมูลมีแค่ 7 วัน ค่ารายชั่วโมงที่ติดกันสัมพันธ์กันเอง และอุณหภูมิ/ความชื้นเปลี่ยนตามเวลาของวัน ซึ่งฝุ่นก็มีรอบวันเช่นกัน ผลจึงเป็นแนวโน้มเบื้องต้นเท่านั้น
5. **อากาศใช้จุดกึ่งกลางของพื้นที่เพียงจุดเดียว** มุมมองทั้งประเทศจึงหยาบที่สุด
6. **ค่าพยากรณ์ยังไม่ได้ตรวจความแม่นยำย้อนหลัง**
7. คำแนะนำสุขภาพเป็นข้อมูลทั่วไป ไม่ใช่คำแนะนำทางการแพทย์
8. Open-Meteo จำกัดจำนวนคำขอต่อนาที ถ้าเปลี่ยนพื้นที่ถี่ ๆ อาจเจอข้อความให้รอ 1 นาที

## เงื่อนไขการใช้ข้อมูล

ก่อนนำไปใช้เชิงพาณิชย์หรือเผยแพร่วงกว้าง ให้ตรวจเงื่อนไขของแหล่งข้อมูลแต่ละแห่ง (โดยเฉพาะ Open-Meteo ที่ฟรีสำหรับการใช้งานที่ไม่ใช่เชิงพาณิชย์ และนโยบายการใช้ไทล์แผนที่ของ OpenStreetMap) และคงการอ้างอิงแหล่งที่มาไว้
