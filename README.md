# PM2.5 เชียงใหม่

หน้าเว็บแสดงค่าฝุ่น PM2.5 รายอำเภอและตำบลของจังหวัดเชียงใหม่ ทำด้วย HTML, CSS และ JavaScript ล้วน ไม่ต้องติดตั้งอะไรเพิ่ม

## ฟีเจอร์

- การ์ดสรุปจำนวนพื้นที่ในแต่ละระดับคุณภาพอากาศ กดเพื่อกรองได้
- แผนที่จุดวัดสีตามระดับ (Leaflet + OpenStreetMap) กดจุดเพื่อดูค่า
- ตารางค้นหาตามชื่อ กรองตามช่วงเวลา ระดับพื้นที่ และอำเภอ คลิกหัวคอลัมน์เพื่อเรียงลำดับ
- ป้ายระดับมีทั้งสีและข้อความ รองรับโหมดมืดอัตโนมัติ

## วิธีใช้

ดาวน์โหลดโปรเจกต์แล้วเปิด `index.html` ในเบราว์เซอร์ได้เลย

แผนที่ต้องต่ออินเทอร์เน็ตเพื่อโหลดไลบรารีและแผนที่พื้นหลัง ถ้าโหลดไม่ได้ แผนที่จะซ่อน และตารางยังใช้งานได้ตามปกติ

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้าเว็บ |
| `style.css` | หน้าตาและสี (มีโหมดมืด) |
| `app.js` | ตัวกรอง ตาราง และแผนที่ |
| `data.js` | ข้อมูลที่หน้าเว็บอ่าน (2 ช่วงเวลา รวม 448 แถว) |

## ข้อมูล

แต่ละแถวใน `data.js` มี: เวลา, ระดับพื้นที่, ชื่อ, อำเภอ, lat, lon, PM2.5 ตอนนี้, เฉลี่ย 7 วัน, สูงสุด 7 วัน (หน่วย µg/m³) และระดับคุณภาพอากาศ

ระดับคุณภาพอากาศแบ่งตามเกณฑ์ PM2.5 ของกรมควบคุมมลพิษ:

| ค่า PM2.5 (µg/m³) | ระดับ |
|---|---|
| 0 – 15 | ดีมาก |
| 15.1 – 25 | ดี |
| 25.1 – 37.5 | ปานกลาง |
| 37.6 – 75 | เริ่มมีผลต่อสุขภาพ |
| มากกว่า 75 | มีผลต่อสุขภาพ |

## ข้อจำกัด

- เวลาในข้อมูลเป็นค่าโดยประมาณ ใช้เวลาที่ดาวน์โหลดไฟล์แทนเวลาวัดจริง เพราะไฟล์ต้นทางไม่ระบุเวลา
- ระดับคุณภาพอากาศคำนวณจากค่า "ตอนนี้" แต่เกณฑ์จริงใช้ค่าเฉลี่ย 24 ชั่วโมง จึงเป็นค่าประมาณ ไม่ใช่ AQI ทางการ
- หลายตำบลมีค่าเท่ากับอำเภอแม่ น่าจะใช้ค่าจากสถานีเดียวกัน
- ไม่มีค่าต่ำสุดย้อนหลัง 7 วัน เพราะข้อมูลต้นทางไม่มี

## อัปเดตข้อมูล

เมื่อมีไฟล์ CSV ใหม่ ต้องแปลงเป็น `data.js` ใหม่ เพราะเบราว์เซอร์อ่านไฟล์ CSV โดยตรงจากการเปิดไฟล์ในเครื่องไม่ได้
